# AGENTS.md（助手记忆）

Doudou **自己**的长期记忆。由 `agent.memory_files` 注入系统提示词，**每轮都会带上**，
所以只写「跨会话仍然成立」的东西（习惯、称谓、长期项目、明确要求过的偏好），
写长了会一直占着上下文预算。

- 主要由助手的 `remember` 工具追加：**写操作有副作用，默认需要人工确认**；
  没有确认通道（HTTP / 飞书）时会被拒绝。
- 回写只追加、不重写，所以你也可以直接手改这个文件 —— 不会被覆盖。
- 自动条目统一落在下面的 `## 助手记录` 小节，格式 `- 事实（YYYY-MM-DD）`。
- **项目约定、代码规范不要写这里**：仓库根的 [`../AGENTS.md`](../AGENTS.md) 是给编码工具
  （Claude Code / OpenCode 等）的项目规范，**不**进助手的提示词，也不是回写目标。
